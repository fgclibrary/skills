# Indexed Grid

在表达多个同层级、等权且不存在先后关系的主题时读取。

## 使用边界

- 适合 2–6 个字段结构一致的并列主题。
- 不用于阶段推进、因果链、双方对比或需要精确查值的数据。
- 每项具有独立状态、交互或操作入口时，才考虑完整卡片。

## 数据契约

```js
{
  kind: "indexed-grid",
  columns: 2,
  items: [
    {
      index: "01",
      title: "主题名称",
      description: "一句简短说明。",
    },
  ],
}
```

- `columns` 支持 1–3 列，默认 2 列。
- `items` 使用稳定的两位编号、短标题和一句描述。
- 同一网格中的项目字段和信息量应当接近。

## 默认视觉行为

- 使用开放式等权网格，不绘制外围边框、卡片圆角或阴影。
- 只保留相邻项目之间的弱分隔线；2×2 时形成中间十字线。
- 每项完整内容块垂直居中。
- 编号位于左侧独立列，并与标题垂直对齐；描述紧随标题。
- 分隔线只建立阅读秩序，不表示项目是独立容器。

## 内容与溢出

- 标题保持一行，描述保持一到两行。
- 列数增加时同步减少每项文字量。
- 超过 6 项时分组或拆页，不缩小整组字号。
- 项目高度差异明显时先改写内容，不使用底部对齐掩盖差异。

## 验收

- 外围没有边线，内部隔线连续且在深浅主题下可见。
- 编号、标题和描述对齐一致。
- 1–3 列以及 2–6 项时没有溢出或 Footer 侵入。

实现来源：`renderIndexedGrid()`、`.indexed-grid` 与 `.indexed-item`。
