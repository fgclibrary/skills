# Metrics

在展示少量、统计口径一致并需要快速比较的数字快照时读取。

## 使用边界

- 适合 1–4 个同一时间范围、业务对象或统计口径下的指标。
- 不用于表达时间趋势、分布、相关性或复杂构成；这些关系应使用 Chart。
- 数字无法在同一判断中比较时，不组成等权指标组。

## 数据契约

```js
{
  kind: "metrics",
  items: [
    {
      value: "42",
      unit: "%",
      label: "转化率",
      description: "从有效线索到确认商机",
      meta: "本季度 · CRM",
    },
  ],
}
```

- `value` 和 `label` 为必需字段。
- `unit`、`description` 和 `meta` 按实际口径填写；没有信息时省略，不写占位。
- `value` 使用可直接显示的字符串，不在 renderer 中计算业务结果。

## 默认视觉行为

- 各指标等宽并在主体区域垂直居中。
- 数值是第一视觉，单位与数值基线对齐。
- 指标之间只使用竖向弱分隔线，不使用卡片背景。
- 标签、说明和口径信息依次降低视觉层级。
- 数字使用等宽数字特性，方便横向比较。

## 内容与溢出

- 默认 2–4 项；单指标只在它确实构成本页唯一证据时使用。
- 数值和单位保持简短，标签通常一行。
- 说明保持一句，`meta` 只保留时间、来源或比较口径。

## 验收

- 所有指标统计口径可解释且彼此可比。
- 数值基线、标签位置和分隔线一致。
- 长单位、负数和不同位数不会破坏列宽或溢出。

实现来源：`renderMetrics()`、`.metric-group` 与 `.metric-item`。
