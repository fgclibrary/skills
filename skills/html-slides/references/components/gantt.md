# Gantt

在月报、季度报告或阶段复盘中，需要同时呈现重点任务、计划周期、交付节点和负责人时读取。

## 使用边界

- 用于静态汇报中的计划排期和阶段跟进，不是项目管理工具。
- 适合 3–8 项重点任务和 3–6 个连续时间区间。
- `execution` 表达执行周期，`milestone` 表达交付节点，`dependency` 表达依赖外部条件的等待或约束周期。
- 只负责呈现，不提供拖动、编辑、缩放、滚动、依赖连线或关键路径。
- 只需要表达先后步骤、不需要比较持续时间时使用 `process`。
- 需要精确核对多个字段但不强调时间跨度时使用 `table`。

## 数据契约

```js
{
  kind: "gantt",
  taskLabel: "重点任务",
  ownerLabel: "负责人",
  columns: [
    {
      id: "week-1",
      label: "8/3–8/9",
      start: "2026-08-03",
      end: "2026-08-09",
    },
    {
      id: "week-2",
      label: "8/10–8/16",
      start: "2026-08-10",
      end: "2026-08-16",
    },
    {
      id: "week-3",
      label: "8/17–8/23",
      start: "2026-08-17",
      end: "2026-08-23",
    },
    {
      id: "week-4",
      label: "8/24–8/31",
      start: "2026-08-24",
      end: "2026-08-31",
    },
  ],
  items: [
    {
      title: "技术交流会规范持续落地",
      owner: "负责人、全员",
      timing: {
        kind: "execution",
        start: "2026-08-03",
        end: "2026-08-31",
      },
    },
    {
      title: "跨团队需求确认",
      owner: "负责人",
      timing: {
        kind: "dependency",
        start: "2026-08-03",
        end: "2026-08-23",
      },
    },
    {
      title: "月中评审",
      owner: "项目组",
      timing: {
        kind: "milestone",
        date: "2026-08-14",
      },
    },
  ],
  period: "2026 年 8 月",
  source: "部门月度计划",
}
```

- `columns` 必须按日期连续排列，日期使用 `YYYY-MM-DD`。
- 每个时间区间宽度相同；区间内的位置按实际日期计算。
- `execution` 和 `dependency` 必须提供 `start` 与 `end`。
- `milestone` 必须提供 `date`，不接受持续时间。
- 所有任务日期必须落在 `columns` 覆盖范围内。
- `taskLabel` 和 `ownerLabel` 可选，默认分别为“重点任务”和“负责人”。
- `period` 与 `source` 必须静态可见。
- 数据层不接受任意 SVG、HTML、坐标或样式。

## 默认视觉行为

- Renderer 直接生成完整 inline SVG，不依赖 Canvas、ECharts 或额外 runtime。
- 左侧为任务名称，中间为等宽时间列，右侧为负责人。
- `execution` 使用主题色实线圆角条。
- `milestone` 使用主题色圆环与中心实心点。
- `dependency` 使用低对比填充和主题色虚线边界。
- 行分隔线保持清楚，时间列网格弱于任务和时间标记。
- 图例根据当前页面实际使用的 `timing.kind` 自动生成。
- SVG 包含可访问的 `<title>` 与 `<desc>`，并可以随页面打印为矢量 PDF。

## 内容与溢出

- 任务名称和负责人默认最多两行；Renderer 必须按各自列宽换行，并通过 SVG 裁切边界保证文字不会进入时间轴或画布外部。
- 两行仍无法容纳时显示省略号；优先改写内容，而不是缩小整体字号。
- 一项只表达一个主要周期或节点；多个独立周期应拆成不同任务。
- 不在周期条内放置长文字或百分比。
- 超过 8 项或 6 个时间区间时，按阶段拆页。
- 不使用动态“今天”线；需要表达汇报截点时使用明确日期的 `milestone`。

## 验收

- 时间列连续，所有周期和节点均落在声明范围内。
- 三种时间表达无需 hover、图例或讲者补充也能被区分。
- 任务名称、时间标记和负责人在同一行准确对齐。
- 任何长度的任务名称和负责人都不会超出所属列。
- SVG 在普通预览、全屏、浅色、深色和打印状态下保持清晰。
- PDF 中的文字、网格、周期条和里程碑均保持矢量。
