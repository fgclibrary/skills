# Table

在观众需要精确查值、逐列对应或比较多条记录时读取。

## 使用边界

- 适合最多约 4 列、6 行的紧凑数据。
- 不用于只需要强调一个结论或少量指标的页面。
- 关系可以通过趋势或构成更快理解时，优先使用 Chart。

## 数据契约

```js
{
  kind: "table",
  columns: [
    { key: "name", label: "名称" },
    { key: "value", label: "数值", numeric: true },
  ],
  rows: [
    { name: "项目 A", value: "128" },
    { name: "合计", value: "128", summary: true },
  ],
}
```

- 每个 `columns[].key` 对应行对象中的字段。
- `numeric: true` 用于数值右对齐和等宽数字。
- `summary: true` 只用于合计或明确的汇总行。
- 单元格只接受可显示文本，不写入任意 HTML。

## 默认视觉行为

- 表格占满可用内容宽度并在主体区域垂直居中。
- 文本左对齐，数值右对齐。
- 只使用必要的水平分隔线，不绘制完整单元格网格。
- 表头使用标签层级，汇总行使用额外上边线和较强字重。

## 内容与溢出

- 常规上限为 4 列、6 行；超出时筛选、分组或拆页。
- 列标题保持简短，正文单元格尽量一行。
- 长说明、段落和嵌套列表不进入单元格。

## 验收

- 列键与每一行数据对应，没有空列或错位。
- 数值列、汇总行和表头层级清楚。
- 深浅主题与打印状态下分隔线可见但不抢占注意力。

实现来源：`renderTable()`、`.data-table-wrap` 与 `.data-table`。
