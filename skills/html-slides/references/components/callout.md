# Callout

在标准内容页中让一个阶段性结论、关键决策、限制或记忆点成为视觉焦点时读取。

## 使用边界

- 适合一个必须被记住的主要判断和一条可选说明。
- 可以作为标准内容页的主要组件，承担整页唯一的关键判断。
- 不用于承载多个要点、步骤、指标或并列结论。
- 判断需要多个证据展开时，先使用相应组件，再在后续页面用 Callout 收束。

## 数据契约

```js
{
  kind: "callout",
  tone: "accent",
  label: "关键决策",
  message: "需要观众记住的完整判断。",
  description: "一句必要的解释。",
  source: "可选来源",
}
```

- `message` 为必需字段。
- `tone` 仅允许 `accent` 或 `neutral`，默认 `accent`。
- `label`、`description` 和 `source` 均可选；没有新增信息时直接省略。

## 默认视觉行为

- 使用单条粗品牌色竖线和开放式文字块。
- 内容块在主体区域垂直居中，主句允许占据较大宽度。
- 不添加卡片背景、完整边框、圆角或阴影。
- `message` 是第一视觉；标签、说明与来源依次弱化。

## 内容与溢出

- 主句通常保持一到三行。
- 说明只保留一句；需要展开论证时换用其他组件或拆页。
- 不通过持续缩小字号容纳段落。

## 验收

- 页面只强调一个判断。
- 标记、标签、主句、说明和来源的层级清楚。
- 页面没有同时存在第二个独立结论。

实现来源：`renderCallout()`、`.callout` 与 `.callout-*`。
