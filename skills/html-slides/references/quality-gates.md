# 交付检查

交付前完整读取并逐项验证。

先在演示目录运行：

```bash
node scripts/validate-deck.mjs
```

命令成功只代表数据契约、逐页 renderer 和本地资源通过确定性检查。下面的内容、
布局和视觉项目仍需在浏览器中逐页验收。

## 内容与叙事

- [ ] 整套演示有清楚的开场、展开、转折和收束。
- [ ] 每页只回答一个主要问题。
- [ ] 标题、观点和主体没有重复同一句话。
- [ ] 语言适合目标受众，没有无必要的技术化或说教语气。
- [ ] 数字、事实、产品状态、来源和外链可追溯。
- [ ] 真实演示的每页 Notes 都是自然可讲的讲者讲稿，不是模板说明或制作元数据。
- [ ] 讲者讲稿按页组织、补充而不复读画面，包含必要转场并符合总时长。

## 页面与布局

- [ ] Page Type 来自叙事职责，而不是使用了哪个组件。
- [ ] Page Type 使用 `page-patterns.md` 定义的默认视觉模式或明确变体。
- [ ] 所有内容位于安全区和 Footer 之间。
- [ ] 标准 Footer 只包含品牌身份和页码，没有演示标题或模板示例文字。
- [ ] 标准内容页的标题与核心观点使用相同宽度和左边缘并自然换行。
- [ ] 带编号的内容项中，编号在左，标题与描述在右；编号与标题垂直居中。
- [ ] 垂直居中移动完整内容块，没有压缩内部行高。
- [ ] 描述默认上对齐；底部对齐有明确变体。
- [ ] 普通内容没有被无依据地包装成卡片。
- [ ] 背景色、边线、圆角和强调色都具有明确语义。
- [ ] 没有通过缩小字号、压缩行高或任意坐标补丁掩盖溢出。

## 组件

- [ ] 组件与信息关系匹配，没有把分类画成流程或把顺序画成卡片。
- [ ] 表格、图表、流程和关系图没有超出常规信息预算。
- [ ] 图表关键值、单位、周期和来源无需 hover 即可阅读。
- [ ] 图表坐标轴、类别和数据标签遵循模板字体层级，没有大于组件正文。
- [ ] Evidence 只包含一个主要证据对象；图片或视频使用 `media`，图表或表格使用 `component`，没有同时设置两者。
- [ ] 图形节点 ID 与边 ID 唯一，边端点有效，自动布局后没有节点重叠。
- [ ] 方向型对比具有明确主次，没有退化成表格或中心对称卡片。
- [ ] 对比两侧标题顶部对齐，两侧列表均无 dimension eyebrow；左侧列表组在剩余区域垂直居中，项目符号与正文垂直居中，右侧编号与结论标题垂直居中。
- [ ] Callout 只表达一个关键判断，没有与同页其他结论重复。
- [ ] 图片和视频保持声明的 `16:9`、`3:4` 或 `9:16` 比例，没有拉伸或强塞进错误画框。
- [ ] 视频使用本地资源、原生 controls、metadata 预载和 poster，不自动播放。
- [ ] 新组件具有明确数据契约、使用边界和跨演示复用价值。
- [ ] 同类编号、标题和描述复用统一结构。

## 工程

- [ ] `node scripts/validate-deck.mjs` 执行成功。
- [ ] 内容、renderer、CSS、资源和 Shell 职责分离。
- [ ] 页面与组件契约只维护在 `scripts/renderers.js`，runtime 与 CLI 没有复制第二套规则。
- [ ] 没有直接修改生成文件。
- [ ] 没有新增不必要的框架、CDN 或远程字体。
- [ ] 图片、视频、poster、字体和其他依赖可以离线访问。
- [ ] 普通外链可追溯且不会被误当作离线运行依赖。
- [ ] 浏览器控制台没有脚本错误。

## 渲染与导出

- [ ] 已逐页检查普通预览和全屏演示。
- [ ] 浅色和深色主题均保持层级与对比度。
- [ ] 长标题、长描述和不同长度的并列项没有溢出或错位。
- [ ] 键盘导航、主题切换、全屏和 Notes 可用。
- [ ] `prefers-reduced-motion` 下内容仍然完整。
- [ ] 打印预览中一张幻灯片对应一页。
- [ ] PDF 保留背景、图片、Footer 和页码。
- [ ] 视频页面在 PDF 中显示 poster，不出现空白视频框或浏览器控制条。
- [ ] PDF 不包含工具栏、导航和 Notes。
