# 布局规则

在调整安全区、间距、对齐、分栏、内容宽度或溢出时读取。

## 1. 画布与安全区

- 使用固定 16:9 逻辑画布，推荐按 1600 × 900 校准。
- 幻灯片内部保持构图比例并整体缩放，不在窄屏重排成网页。
- 标准内容页左右安全边距约为画布宽度的 `6%`。
- 顶部与底部保持稳定空间，正文不能侵入浏览器控制、Footer 或页码区域。
- 标准内容页的标题、核心观点和正文默认共享同一左边缘。
- 标准内容页的标题和核心观点使用内容区 `100%` 宽度并自然换行。
- Cover、Section 和 Summary 使用 `page-patterns.md` 规定的专属构图。

## 2. 间距语义

使用四级关系，不按局部感觉随意添加 margin：

| 级别 | 关系 |
| --- | --- |
| `inline` | 编号与标题、标签与文字 |
| `content` | 标题与描述、数值与口径 |
| `item` | 列表项、并列模块与节点 |
| `group` | 独立内容区与主要分组 |

同一页面的重复关系使用同一级别。留白不足时优先删减内容，不压缩所有间距。

## 3. 对齐

- 带编号的内容项中，编号在左侧独立编号列，标题与描述在右侧内容列。
- 内容项的编号与标题处于同一标题行，并在垂直方向居中。
- 内容项的标题和描述拥有相同左边缘。
- 内容项的描述默认紧跟标题并上对齐，不使用 `margin-top: auto` 推到底部。
- 需要垂直居中时，移动完整内容块，不缩小其内部行高和间距。
- 底部对齐必须是明确命名的组件变体。

## 4. 分栏

推荐关系：

| 内容关系 | 比例 |
| --- | --- |
| 两个等权区域 | `1 / 1` |
| 两个主次区域 | `35 / 65` 或 `40 / 60` |
| 三个等权区域 | `1 / 1 / 1` |

- 等权内容使用等宽栏；
- 只有真实主次关系才使用非对称比例；
- 两栏和三栏是常规上限；
- 优先用留白分栏，只有持续横向对应时才增加弱边线。

## 5. 宽度与换行

- 标题最多两行。
- 描述保持一到两句。
- 长段正文不要占满整行，建议限制在内容区约 `55–68%`。
- 列数增加时同步减少每项文字量。
- 不使用强制 `<br>` 模拟本应自然发生的换行，除非换行本身具有明确语义。

## 6. 容器与边界

- 普通并列内容优先使用留白或单条弱边线。
- 不默认把列表、指标、概念和步骤包装为卡片。
- 圆角容器只在内容需要独立边界时使用。
- 背景色必须对应明确语义，不为相邻区域分配装饰性色。
- 基础内容不使用阴影；覆盖层和浏览器控制除外。
